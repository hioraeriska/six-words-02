A complete story in exactly six words, written for the
[Six Words, One Story](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410)
bounty on make.fun: a flash-fiction editor judges each entry on whether
six words can carry a whole life.

> I kept his voicemail. Still do.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the
story to `entry.txt` in the output directory. No randomness — two runs
write byte-identical files.

Run it: `MAKEFUN_OUTPUT_DIR=out python3 main.py` → `out/entry.txt`
(6 words, 31 characters).
